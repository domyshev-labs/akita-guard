# Проверка проекта

Дата: 2026-10-17.

- Xcode toolchain 27.1 (27A9275), iOS SDK 27.1.
- Минимальная версия приложения iOS 17, только iPhone.
- Debug build для generic iOS Simulator: BUILD SUCCEEDED.
- Debug build для generic iOS device, CODE_SIGNING_ALLOWED=NO: BUILD SUCCEEDED.
- Swift Package: 11 тестов, 0 ошибок.
- Демо запущено на отдельном iPhone 15 Pro Max Simulator с iOS 26.5.
- Проверены реальные снимки главного экрана, формы добавления, настроек,
  светлой и тёмной темы. Снимки содержат только вымышленные IP.
- Токен сервера не читался и не включён в проект. Серверная конфигурация и
  реальные разрешения в ходе создания приложения не менялись.
- Подпись Apple, установка на физический iPhone и сквозной запрос с реальным
  токеном не выполнялись: эти шаги описаны в README.md.
- Зависимостей для скачивания нет; сборочные cache и
  DerivedData расположены вне проекта и в архив не включаются.

В приложении нет аналитики, фоновой службы VPN и автоматического определения
публичного IP телефона. Оно управляет уже установленным API Akita через
существующий маршрут Tailscale.

## Название и иконка

Проект, схемы, модули и Bundle ID переименованы в AkitaGuard.
После переименования повторно прошли сборки Simulator и iOS device без подписи,
а также 11 тестов. Иконка RGB 1024×1024 без alpha подключена к AppIcon;
имя Akita Guard и значок проверены на домашнем экране iPhone 15 Pro Max Simulator.
Исходная иллюстрация и промпт сохранены в Brand/ и ICON.md.

## Подготовка публичного репозитория

примеры; адрес своего сервера пользователь вводит в настройках. Локальные
скриншоты, настройки Xcode пользователя и результаты сборки исключены из Git.
